Online room

पहले Firebase settings भरें। फिर एक खिलाड़ी Create room दबाए और दूसरे मोबाइल पर उसी room code से Join करें।

लाइव गेम के लिए Firebase config, Anonymous Authentication और सुरक्षित Rules सेट करना जरूरी है।

Firebase settings

Firebase Console → Project settings → Your apps → SDK setup and configuration में CDN/Config चुनें। नीचे के मान अपने config से भरें। ये आपके इसी ब्राउज़र में सेव होंगे।

API key और appId वेबसाइट कॉन्फ़िगरेशन का हिस्सा होते हैं; कभी भी service-account/private key यहाँ न डालें।
